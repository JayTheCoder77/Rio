# Docs Spec — Rio

**Purpose**:  
Comprehensive, clean documentation for developers using Rio (GitHub App + CLI).

**Inspiration**: Modern developer docs (clean, readable, good hierarchy, dark/light support).

---

## Layout

- Left sidebar: Documentation navigation (sticky)
- Main content area: Markdown-rendered pages
- Optional right sidebar: Table of contents (on wider screens)

---

## Sidebar Structure (Suggested)

- Getting Started
  - Introduction
  - Installation
  - Quickstart
- GitHub App
  - Installing the App
  - Connecting Repositories
  - How reviews work
- CLI
  - Installation
  - Authentication (API Keys)
  - Commands reference
  - Configuration
- Concepts
  - How Rio reviews code
  - Context & memory
- Guides
  - Best practices
  - Troubleshooting
- API Reference (if applicable)
- Changelog

---

## Content Guidelines

- Clear, direct language.
- Short paragraphs + good use of headings, code blocks, and lists.
- Code examples should be copyable.
- Screenshots / short clips where helpful (especially for GitHub App flow).
- Dark / light mode fully supported.
- Search bar at the top of the docs (highly recommended).

---

## Key Pages Priority

1. Getting Started / Quickstart
2. GitHub App installation & usage
3. CLI installation + authentication
4. Core concepts
5. Troubleshooting
