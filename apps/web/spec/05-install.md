# Install Page Spec — Rio

**Purpose**:  
Show the two official ways to start using Rio.

**Inspiration**: Clean product install pages (clear choice, no confusion).

---

## Layout

Centered content with strong hierarchy.

**Heading**:  
**Get started with Rio**

**Subtext**:  
Choose how you want to use Rio.

---

## Two Options (Side by side on desktop, stacked on mobile)

### Option 1 — GitHub App
- Title: **GitHub App**
- Short description: “Review pull requests directly in GitHub with zero setup friction.”
- Primary button: **Install GitHub App** → redirects to GitHub App installation flow
- Optional secondary text: “Recommended for most teams”

### Option 2 — CLI
- Title: **CLI**
- Short description: “Run Rio locally and integrate it into your existing workflows.”
- Primary button: **View CLI Docs** or **Install CLI** (links to the relevant docs section)
- Supporting note: “Requires an API key (create one after signing in)”

---

## Design Notes

- Both options should feel equally important visually.
- Use medium-to-large cards or clean columns.
- Clear visual distinction between the two paths without making one feel secondary.
- After login, this page can still be useful as a reference.
- Keep the page short — users should decide and act quickly.
